# Solicitud de requisitos para publicación productiva

**Asunto:** Elementos pendientes para publicación de Portal Libre Expresión

Portal Libre Expresión se encuentra desplegado y validado técnicamente en ambiente productivo. Para avanzar con la publicación definitiva requerimos los siguientes elementos:

| Requisito | Responsable |
|---|---|
| Dominio oficial | Libre Expresión |
| Acceso DNS | TI cliente |
| Configuración SMTP | TI cliente |
| NAT 443 hacia Portal | Infraestructura |
| Certificado TLS | TI / Infraestructura |
| Usuarios iniciales | Cliente |
| Aprobación salida producción | Cliente |
| Política backup externo | Cliente/TI |

Actualmente PROD está disponible internamente y queda pendiente la habilitación externa.
